사용설명서
1
반 선택 또는 추가
학생 이름 카드 오른쪽 드롭다운에서 반을 선택하거나, + 버튼으로 새 반을 추가하세요.
2
학생 이름 입력
왼쪽 칸에 이름을 한 줄에 한 명씩 입력하세요.
엑셀(CSV)에서 복사해서 붙여넣기도 되고, 엑셀 업로드 버튼으로 파일을 바로 올릴 수도 있어요.
3
모둠 뽑기
모둠을 뽑아주세요! 버튼을 누르면 자동으로 배치됩니다. 지난 기록을 참고해 겹침을 최소화해요.
4
모둠장 지정 (선택)
결과 화면에서 학생 이름을 클릭하면 ⭐ 모둠장으로 지정됩니다.
5
결과 저장
결과 화면 하단 결과 저장하기를 누르면 기록이 보관됩니다.
열쇠 버튼
과거 배치 기록 확인 및 삭제, 고정 학생 설정이 가능합니다.
추가 기능
구글 로그인
오른쪽 위 구글 로그인 버튼으로 로그인하면 기록이 구글 계정에 저장되어 다른 기기에서도 동일하게 사용할 수 있어요.
구글 시트 연동 (GAS)
오른쪽 위 GAS 설정에 구글 앱스스크립트 URL을 연결하면 모둠 결과와 모둠장 횟수가 구글 시트에 자동 저장됩니다.
